# Kulaklık Kablosunun Kendiliğinden Düğüm Antlaşması

## Resmi Statü

Bu depo, cebinize attığınız kulaklık kablosunun **üç saniye içinde** kendi kendine düğüm atmasını düzenleyen bağlayıcı uluslararası protokoldür.

Antlaşma 1927'de (muhtemelen) Cenevre'de, bir tramvay durağında, kimsenin hatırlamadığı bir diplomat tarafından paraflanmıştır. Onay belgesi kayıptır. Yine de yürürlüktedir.

## Bilimsel Gerekçe (Ciddi)

Fizik, kablonun düz durmasının evrene aykırı olduğunu söyler. Entropi artar. Cep küçülür. Düğüm çoğalır. Bu yazılım o gerçeği **reddetmez**, resmi evrak haline getirir.

## Kurulum

```bash
python3 antlasma.py
```

Bağımlılık yoktur. Çünkü düğüm zaten kendi kendine yeter.

## Kullanım

Program çalıştığında:

1. Kablonun mevcut diplomatik durumunu ölçer.
2. Rastgele ama **hukuken bağlayıcı** bir düğüm türü seçer.
3. Antlaşmanın ilgili maddesini okur.
4. Çözmeyi dener. Başarısız olur. Bu başarısızlık da protokoldür.

## Madde Özeti

- **Madde 1:** Kablo, gözetimsiz kaldığı her saniye düğüm atma hakkına sahiptir.
- **Madde 2:** Kullanıcının "ben düz koymuştum" ifadesi delil değildir.
- **Madde 3:** Çözme işlemi en az üç kere başarısız olmak zorundadır.
- **Madde 4:** Bluetooth kulaklık bu antlaşmadan kaçamaz; hayalet kablo vardır.
- **Madde 5:** İtiraz mekanizması kablonun kendi içindedir. Kimse bulamamıştır.
